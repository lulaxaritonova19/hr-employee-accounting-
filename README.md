# hr-employee-accounting-

Система кадрового учета сотрудников для HR-специалиста.

## 🛠 Технологический стек

- **Backend:** Node.js + Express
- **База данных:** PostgreSQL
- **Frontend:** HTML5, CSS3, JavaScript (Vanilla)
- **Дополнительно:** IMask для масок ввода

## ✨ Функционал

- ✅ Полный CRUD сотрудников:
  - ФИО, дата рождения, паспорт, телефон, адрес, зарплата, дата приема, отдел, должность
- ✅ Фильтрация таблицы по отделу и должности
- ✅ Поиск сотрудников по ФИО
- ✅ Маски ввода:
  - Паспорт: `0000 000000`
  - Телефон: `+7 (000) 000-0000`
- ✅ Мягкое удаление (увольнение):
  - Сотрудник помечается статусом "Уволен"
  - Не удаляется из базы данных
  - Редактирование заблокировано для уволенных

## 🚀 Установка и запуск

### Требования

- Node.js (v14 или выше)
- PostgreSQL (v12 или выше)
- npm (менеджер пакетов)

### Пошаговая инструкция

1. **Клонировать репозиторий**

   ```bash
   git clone https://github.com/lulaxaritonova19/hr-employee-accounting-.git
   cd hr-employee-accounting-
   ```

2. **Установить зависимости**

   ```bash
   npm install
   ```

3. **Настройка базы данных**
   Выполните SQL из файла database.sql в pgAdmin:
   Создастся БД hr_database
   Создастся таблица employees
   Добавятся тестовые данные

4. **Настройка подключения к БД**

   Откройте файл `server/database.js` и укажите свой пароль (если есть):

   ```javascript
   const pool = new Pool({
   	host: 'localhost',
   	user: 'postgres',
   	password: 'ваш_пароль',
   	database: 'hr_database',
   	port: 5432,
   })
   ```

5. **Запустить сервер**

   ```bash
   node server/server.js

   ```

6. **Открыть приложение**

   Перейдите в браузере по адресу:

   ```
   http://localhost:3000
   ```
