# hr-employee-accounting-

Стек: JS, MySQL, HTML/CSS

Функционал:
- Полный CRUD сотрудников (ФИО, дата рождения, паспорт, телефон, адрес, зарплата, дата приема, отдел, должность)
- Фильтрация по отделу/должности
- Поиск по ФИО
- Маски ввода для паспорта (`0000 000000`) и телефона (`+7 (000) 000-0000`)
- Мягкое удаление: при увольнении сотрудник помечается статусом "Уволен" (не удаляется из БД)
- Редактирование заблокировано для уволенных сотрудников
